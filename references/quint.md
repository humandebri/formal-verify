# Quint
Read application-modeling.md for the protocol workflow. Use `quint typecheck model.qnt`, `quint test model.qnt`, `quint run model.qnt --invariant=safe --max-steps=20`, and `quint verify model.qnt --invariant=safe --max-steps=10 --backend=apalache`. Check installed CLI help for version-specific options, including TLC and ITF trace export. Preserve exact invocation and raw traces. The collector supports explicit modes and backend selection; review its UNKNOWN result manually.
Simulation is TESTED, completed bounded verification is BOUNDED_SAFE, and completed exhaustive TLC checks only establish safety of the finite model (not the implementation). Record state constraints, deadlock settings, bounds and search completion; do not infer liveness from safety. Inductive proof requires initiation and consecution. Preserve deterministic negative tests and map trace actions to public implementation events. See https://quint-lang.org/ .
